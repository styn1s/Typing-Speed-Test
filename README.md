# ⌨️ Typing Speed Test
A clean, responsive typing speed test application. This project allows users to measure their typing speed (WPM) and accuracy with a simple, focused interface.

![Screenshot of the app](/assets/images/screenshot.png)

## ✨ Features
- Real-time Feedback: See your WPM (Words Per Minute) and accuracy update as you type

- Responsive Design: Works seamlessly on desktops, tablets, and mobile devices (down to 320px width)

- Focused Interface: Minimalist and distraction-free environment to help you concentrate on your typing

- Instant Results: Get your final score immediately after completing the test

## 🚀 Live Demo
Try the live version here: https://styn1s.github.io/Typing-Speed-Test/

## 🛠️ Technologies Used
- HTML5 - Structure

- CSS3 - Styling and responsive layout

- Vanilla JavaScript - Logic and interactivity

## 🧪 How to Use
1. Start the test: First choose a test difficulty and mode, then just click the text or the starting button

2. Type the text: Type the displayed text as accurately and quickly as you can

3. Track your progress: Your WPM and accuracy will be updated in real-time

4. View your results: Once you finish the text, your final score will be displayed
